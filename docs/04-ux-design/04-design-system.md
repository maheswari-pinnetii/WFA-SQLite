# 04. Design System

## Stackly Unified Design System

### Color Palette
* **Primary Emerald**: `#10b981` (Emerald-500), `#059669` (Emerald-600)
* **Background Dark**: `#0f172a` (Slate-900), `#020617` (Slate-950)
* **Card & Surface**: `#1e293b` (Slate-800), `#334155` (Slate-700)
* **Text Colors**: White (`#ffffff`), Slate-300 (`#cbd5e1`), Slate-400 (`#94a3b8`)
* **Accents**: Blue-500 (`#3b82f6`), Sky-400 (`#38bdf8`), Amber-500 (`#f59e0b`), Rose-500 (`#ef4444`)

### Typography
* **Primary Font**: `Plus Jakarta Sans`, sans-serif
* **Headings**: Semi-bold to Black, tracking-tight
* **Body & Data**: Regular to Medium, anti-aliased

### Key Component Specifications
1. **KPI Cards**: Standardized high-contrast containers featuring bold values, subtle trend badges, and Lucide icons.
2. **Tables / Data Grids**: High-density rows, fixed headers, subtle hover highlights, integrated server-side pagination controls.
3. **Buttons & Controls**: Primary Emerald action buttons, secondary outlined Slate buttons, Shimmer animations for call-to-actions.
4. **Dialogs & Overlays**: Backdrop blurred modals (`backdrop-blur-md`), dark surface headers, explicit action footers.
5. **Theme Support**: Dark mode default with high contrast enterprise readability.
