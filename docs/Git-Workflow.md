# Git Workflow & Branching Strategy

This document defines the Git version control conventions, branching model, and Pull Request procedures for the **Stackly Workforce Analytics Platform**.

---

## 🌿 Branching Model

- `main`: Production-ready code.
- `develop`: Integration branch for new features.
- `feature/<feature-name>`: Individual feature work.
- `fix/<bug-name>`: Bug fixes.

---

## 📝 Commit Conventions

Follow Conventional Commits format:
- `feat: add voice search support to enterprise header`
- `fix: resolve search input alignment clipping`
- `docs: update API documentation`
- `style: standardize Lucide React icons`
